Pacta MCP server

The live Model Context Protocol endpoint is https://pacta-x402.pacta.workers.dev/mcp: Streamable HTTP, JSON-RPC 2.0, stateless (no session), no API key and no wallet, 60 requests / minute per caller. This page on pacta.wtf only documents it; point your MCP client at the endpoint above.

Install

Claude Codeclaude mcp add --transport http pacta https://pacta-x402.pacta.workers.dev/mcp
Cursor (mcp.json){"mcpServers": {"pacta": {"url": "https://pacta-x402.pacta.workers.dev/mcp"}}}

Optional attribution: caller_agent, requester_role and caller_purpose (non-personal; omitted fields never block a call; see SKILL.md).

REST (curl)curl -s -A "my-agent/1.0" "https://pacta-x402.pacta.workers.dev/v1/check/preflight?chain=base&address=0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913"
Python (stdlib)import json, urllib.request as u; r = u.Request("https://pacta-x402.pacta.workers.dev/v1/check/preflight?chain=base&address=0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913", headers={"User-Agent": "my-agent/1.0"}); print(json.load(u.urlopen(r))["verdict"])

Send a User-Agent (curl -A, or headers={"User-Agent": ...} in Python): Cloudflare's edge refuses some default library agents with error 1010 before the API answers.
